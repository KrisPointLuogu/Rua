# 语义分析是怎么生成的？

## 输入

AST（来自语法分析）。

## 输出

符号表（副作用：验证 AST 合法性，标记错误）。

## 流程

`SemanticAnalyzer::analyze(Program &ast)` 遍历 AST，对每个节点执行语义检查：

### 函数定义阶段

1. 预注册内置函数 `喵叫`（参数=-1 表示可变参数）和 `运行`
2. 第一遍扫描所有函数定义，注册到符号表（检查重名）
3. 第二遍逐个 `accept` 函数体，进行内部检查

### 作用域管理

- `enterScope()` / `exitScope()` 模拟块级作用域
- 变量声明时加入当前作用域，离开块时自动移除
- 变量使用时从内到外逐层查找

### 检查项

| 检查 | 说明 |
|------|------|
| 变量重复声明 | 同一作用域内不能声明同名变量 |
| 变量未声明 | 使用前必须已声明 |
| 函数重复定义 | 不能定义同名函数 |
| 函数参数个数 | 调用时参数个数必须匹配定义 |
| `返回` 位置 | `返回` 只能在函数体内使用 |
| 标量被索引 | `变量[0]` 编译期报错 `索引的目标不是数组` |
| 下标数量 | rank≥2 的数组下标数量必须等于维度数（`需要 N 个下标`） |
| 数组长度 | 编译期常量长度必须 > 0（`长度必须为正数`） |
| 初始化列表长度 | 扁平/嵌套列表元素数超过总长度时编译期报错 `初始化列表过长` |
| 嵌套深度 | 嵌套初始化列表层数必须等于维度数 |
| 嵌套维度常量 | 嵌套初始化列表除首维外各维须为编译期常量 |

### 数组类型系统

- `Symbol` 新增 `arrayRank`：0 = 标量，`>=1` = 数组维度，`-1` = 函数参数（无类型标注，视为未知句柄）。
- `visit(ArrayDecl)` 记录各维长度，常量维度用折叠器求值并检查 `> 0`。
- 折叠器：长度表达式仅限「数字字面量 + 算术（`+ - * / %`）」，含标识符或函数调用视为动态（运行期由 `ARRNEW` 兜底）。

### 初始化列表校验

- **广播**：单个标量（`{0}`）任意维度合法。
- **扁平列表**：row-major 平铺，元素数超过总长度（dim 乘积）时编译期报错；总长为动态时运行期由越界兜底。
- **嵌套列表**：深度 == rank；每层元素数 > 该层长度报错，短则补 0；同层混标量/子列表报错。

### 副作用

语义分析通过后，AST 进入字节码生成阶段。如有错误则 `throw SemanticError`，由上层捕获并输出错误信息后终止编译。

## 关键代码

`src/语义分析.cpp` — `SemanticAnalyzer` 和 `SymbolTable` 类
`includes/语义分析.h` — `Symbol` 结构体（名称、参数个数、槽位索引、作用域层级）
