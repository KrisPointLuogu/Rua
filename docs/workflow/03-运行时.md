# 工作流程 03 — 运行时

> AST 如何被解释执行：值系统、环境链、exec 分发循环、函数调用与喵叫。
> 涉及 includes/runtime.h（JIT 分发点一并说明，细节见 04-快路径.md）。

## 一、值系统：标签联合 Value

```
Value { type, num, str, arr }
  V_NUM  数字     long long
  V_STR  字符串   char*（共享指针，不深拷贝）
  V_ARR  数组     Array*（句柄，共享指向）
```

- 构造函数 `num_val(n)`；字符串/数组直接组装结构体；
- **数组是句柄语义**：赋值/传参只复制 `Array*` 本身，
  多个变量指向同一份数据——`b = a` 之后 `a[0] = 9` 则 `b[0]` 也是 9；
- `print_val(v)`：数字 `%lld`、字符串原样、数组打印字面量「数组」。

## 二、环境链：Env 与空闲链表

```
Env { parent, bindings[], count, cap, next_free }
Binding { name, val, next_free }
```

- 作用域就是一条 parent 链：全局环境 parent=NULL，
  每次函数调用 `env_new(ctx->env)` 挂一个子环境；
- `env_get(e, name)`：沿链由内向外逐层线性查找，找不到报错；
- `env_set(e, name, v)`：沿链找到即改；**各层都没有则在当前层新建**
  （隐式声明，变量无需先声明即可赋值）；
- `env_bind(e, name, v)`：在指定层追加绑定（声明/形参用）。

**空闲链表复用**：函数调用严格后进先出，所以子环境用完可以安全回收——
`env_release(e)` 把 Env 和 bindings 数组压回 `env_freelist` /
`binding_freelist`，下次 `env_new` O(1) 取用，避免高频 malloc/free。

## 三、求值上下文 Ctx 与返回传递

```
Ctx { env, returning, retval }
```

Rua 没有「表达式求值中途返回」的异常机制，返回语句靠两个标志向上传递：

1. `N_RETURN` 求值后置 `ctx->returning = 1`，retval 存返回值；
2. `N_BLOCK` / `N_PROG` / `N_WHILE` 每执行完一条语句就检查该标志，
   为真立即停止继续执行；
3. `exec_call` 看到标志后取 `child.retval` 作为调用结果。

## 四、解释主循环：exec()

`exec(n, ctx)` 按 `n->kind` switch 分发，返回值为表达式求值结果：

```
N_NUM      → num_val(n->num)
N_STR      → 组装 V_STR（str 直接指向 AST 内的字面量）
N_IDENT    → env_get(ctx->env, n->str)
N_VAR      → 求初值 → env_bind 当前层          （声明即绑定）
N_ARRAY    → 求广播初值 → calloc Array 填充 len 份 → env_bind
N_ASSIGN   → 求右值 → assign_target()：
               目标 N_IDENT → env_set
               目标 N_INDEX → array_set（越界报错）
N_INDEX    → index_read()：求基址+下标 → array_get（越界报错）
N_BINARY   → 求左、求右 → apply_binop(op, a, b)
N_CALL     → exec_call(n, ctx)                 ← 函数调用入口
N_IF       → 条件真执行 body，否则执行 elseB（可空）
N_WHILE    → 循环「条件→体」，体执行后检查 returning 提前退出
N_RETURN   → 置 returning/retval（见上）
N_FUNC     → 0（函数定义已在编译期注册，运行期遇到直接跳过）
N_PROG/N_BLOCK → 逐条执行，returning 时提前结束，返回最后一条的值
```

条件判断 `is_true(v)`：数字非 0 为真、字符串非空为真、数组恒为真。

## 五、二元运算：函数指针表

```
static BinOp bin_table[256] = {
    [TK_PLUS] = bin_add, [TK_MINUS] = bin_sub, …
};
apply_binop(op, a, b) → bin_table[op](a, b)
```

GNU C 指定初始化器在编译期填表，运行期一次下标 + 间接调用完成分发。

| 运算 | 类型规则 |
| --- | --- |
| `+` | 任一侧是字符串 → 另一侧转文本做拼接；否则数字相加 |
| `-` `*` `/` `%` | 只接受数字；除数/模数为 0 报错 |
| `==` `!=` | 双字符串比内容；双数字比数值；类型不同视为不等 |
| `>` `<` `>=` `<=` | 只接受数字 |

## 六、函数调用：exec_call()

```
exec_call(n, ctx)
  ├─ n->str == "喵叫"？
  │    ├─ 逐实参：求值 → print_val 立即打印（参数间无分隔符）
  │    ├─ 全部打完 → printf("\n")
  │    └─ 返回 0
  ├─ find_fn(n->str)                    找不到 → 未定义的函数
  ├─ 形参个数校验（不匹配报错）；参数 >64 报错
  ├─ 先求值全部实参 → arg_vals[]
  ├─ [OPTIMIZATION] f->jittable？ → return jit_invoke(f, arg_vals, nargs)
  ├─ Env *e = env_new(ctx->env)         新建子环境
  │    env_bind(e, 形参[i], arg_vals[i])
  ├─ Ctx child = { .env = e, … }        子上下文挂子环境
  │    r = exec(f->body, &child)
  │    env_release(e)                   回收进空闲链表
  └─ 返回 child.returning ? child.retval : r
```

要点：

- **实参先全部求值再绑定**（求值顺序即书写顺序）；
- 函数体内可见性 = 自己的形参/局部 + 调用方作用域链（词法上即全局），
  因为子环境 parent 指向调用者环境；
- 无显式 `返回` 的函数返回**函数体最后一条语句的值**；
- 递归/互调没有特殊处理——每次调用都走同一套 find_fn → 新环境流程。

## 七、喵叫 打印规则

- 参数逐个**求值一个打印一个**（不是先全求值再打印）——
  所以出错时前面的参数已经打出去了；
- 参数之间**无分隔符**：`喵叫(10,20)` 输出 `1020`；
- 结尾固定换行：输出为 `1020\n`；
- 数组实参打印「数组」二字；字符串原样；数字十进制。
