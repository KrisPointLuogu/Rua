# 词法分析是怎么生成的？

## 输入

Rua 源码字符串（UTF-8）。

## 输出

`vector<令牌>` — 扁平 token 列表。

## 流程

1. **UTF-8 → UTF-32**  
   源码用 `UTF8转UTF32()` 转为 UTF-32，方便逐字符处理中文。

2. **逐字符扫描**  
   `词法分析器::分析()` 从位置 0 遍历到末尾，每个字符进入对应分支：

   | 字符 | 动作 |
   |------|------|
   | `空格` `\t` `\r` `\n` | 跳过；`\n` 额外生成 `换行符` token |
   | `#` 单行注释 | 吃到行尾 |
   | `#*` 多行注释 | 吃到 `*#` |
   | `'` `"` `“` `‘` | 调用 `ab匹配` 配对闭合引号，生成 `字符串` token |
   | `0-9` | 连续读数字，生成 `数字` token |
   | 中/英文字符 | 连续读标识符，查关键字表（`喵` `如果` `变量` 等），匹配到则生成对应关键字 token，否则生成 `标识符` token |
   | `+` `-` `*` `/` `%` `=` `!` `>` `<` `(` `)` `{` `}` `[` `]` `,` `;` | 识别单字符或双字符运算符（`<=` `>=` `==` `!=` 等），生成对应 token |

3. **全局 token 列表**  
   所有 token 通过 `新令牌()` 函数追加到全局 `令牌列表`，lexer 结束后返回此列表给 parser。

## 关键代码

`src/词法分析器.cpp` — `分析()` 方法
`includes/词法分析器.h` — `令牌类型` 枚举（函数=1, 如果=2, …, 小于等于=45）
