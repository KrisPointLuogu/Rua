# Rua —— 项目码风文档

> Tips: 为了宣传、非程序员读取着想，码风文档规范可能有违你的习惯。

## 命名规范
1.变量名、函数名等标识符全部使用中文命名，如有无法使用中文处，可使用对应的英文命名。
2.如是英文命名，请使用大驼峰命名规范方法，如使用该方法有损可读性等，可使用全大写、全小写方法，且可添加下划线。
3.如使用中文名，但完整名称过长，可适当简写，并在旁边加以注释补充完整名称。
4.头文件名称应当与其源文件保持一致。

## 格式规范
1.缩进: 缩进请使用单个Tab，禁止使用空格。
2.大括号: 左侧括号禁止换行。
	
## 注释规范
1.注释掉的代码: 在提交时，删除该被注释的代码。
2.公开函数: 请使用 /** */ 说明参数功能，必要时返回值格式一并说明。

## 异常处理规范
1.必须使用输出、记录到XXX等形式处理异常。
2.禁止空吞异常，除非用于兜底保证不崩溃。

## 其他规范
1.请勿使用任何第三方库、NuGet包等，推荐使用标准库自行实现功能。
2.如果使用了某个系统的专属API方法，那么需搭配条件编译包裹使用。
